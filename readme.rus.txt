1. Что здесь.
-------------
Kronos3vm - это программный эмулятор компьютера Кронос, который разрабатывался в 1984-1991 г.г. в Новосибирске. На эмуляторе установлена ОС Excelsior iV, а также есть копия всех исходных текстов ОС Excelsior, готовые к сборке системы.
В подпапке doc Вы найдете документацию по процессорам Kronos и по ОС Excelsior.

Подробнее о Кроносе тут: https://kronos.ru/
GitHub: https://github.com/leok7v/kronos 
GitHub клон: https://github.com/hady-exc/kronos


2. Как запустить.
-----------------
В командной строке Windows наберите:

   Kronos3vm xd0.dsk xd1.dsk ENTER

Эмулятор запустится, загрузит ОС, и Вы получите приглашение

  user:

В ответ наберите sys ENTER

После входа приглашение будет выглядеть так:

  17:12 sys !

где 17:12 - текущее время, а sys - имя текущей директории. 
Дальше можно набирать команды. Подробнее о командах ниже, а для начала попробуйте ls.

3. Настройка окна командной строки Windows.
-------------------------------------------
Эта настройка необязательна, большинство утилит будут работать и так, поэтому настройку можно отложить. Но редактором текста ex будет почти невозможно пользоваться из-за искаженного расположения текста на экране, и если Вам он будет нужен, проделайте эти шаги.

Шаг 1. 
Этот шаг необходим только если у Вас Windows 11. Если Вы используете Windows более старых версий, его можно пропустить.
На Windows 11 нужно переключить терминал на "старый" Windows Console Host вместо умолчательного Terminal Windows.
- Откройте Settings -> System -> For developers.
- Найдите в списке плашку Terminal, в ней в выпадающем списке справа выберите Windows Console Host.
- Закройте Settings

Шаг 2.
Установите для консоли размер окна и буфера окна в 50 строк по 80 символов. 
Для этого:
- запустите команднуюю строку, щелкните правой кнопкой по левой иконке в заголовке окна, и из выпавшего меню выберите либо Properties либо Defaults. В первом случае Вы отрегулируете только это окно, во втором - зададите новые значение для всех консольных окон, которые будут после этого запущены
- в появившемся окне настроек установите значение 50 строк по 80 символов и для окна и для буфера окна
- при необходимости перейдите во вкладку Font, и подберите шрифт, при котором все окно будет помещаться на Ваш экран
- щелкните кнопку OK

Что дальше?
-----------
Командный интерфейс ОС Excelsior во многом схож с любым Unix'ом. Утилиты ls, cd  помогут изучить содержимое диска. Кроме этого есть аналог Norton Commander'а, который называется kc, в котором это делать удобнее. Есть cp, rm, ln, cat, и много чего еще.
Редактор файлов - ex.
Компилятор Modula-2 - mx (примечание: в документации он назван m2, но она устарела в этом месте).
Просмотрите документацию, там перечислены остальные утилиты, доступные для запуска.
Аналоги .bat-файлов имеют расширение ".@" или "sh", исполняемые файлы - ".cod".
Чтобы запустить исполняемый файл, достаточно набрать его имя без расширения.
Большинство утилит, при запуске с ключом "-h" выдают подсказку.
